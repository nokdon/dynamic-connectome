# Contributions

The project owner directed the research questions, proposed and reviewed hypotheses, selected and operated experiments, interpreted outcomes, and made continuation and stop decisions. This account incorporates the owner's latest clarification of the code's origin.

The early JAX implementation was the owner's own code, transferred from another local repository into DC. Later implementation was primarily produced with coding agents. The public-release preparation also used a coding agent for repository discovery, checkpoint evaluation, modularization, test and documentation work, and installation checks. Project ownership and the use of implementation assistance are described separately.

The repository is intended to make the work assessable through executable models, stated experimental boundaries, and reproducible checkpoint results. It does not claim sole invention of straight-through estimators, message-passing networks, surrogate-gradient spiking, or teacher distillation.

## Suggested portfolio description

> **Dynamic Connectome — Independent ML research project.** Directed experiments on learned sparse routing and hybrid spiking models in JAX. Prepared reproducible checkpoint evaluation against dense and budget-matched sparse controls; audited checkpoint selection and numerical execution assumptions.

After the project is actually published, “released reproducible checkpoint evaluations” can replace “prepared.” A quantitative bullet can state that the evaluated 44-edge graphs reduced MSE by approximately 25% versus the evaluated random sparse controls on the stated synthetic target-local task. It should not claim hardware acceleration, biological topology recovery, or benchmark leadership.
